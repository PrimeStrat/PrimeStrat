### What I do

I make games. I come up with the idea, figure out what makes it fun, and build it until it's ready to play. Along the way I've also made mods, tools, and websites for games.

I'm open to **contract work**, and one day I want to start my own **game studio**.

| | |
|---|---|
| **Designing games** | Working out the rules, goals, and moments that make a game fun. |
| **Building games** | Turning ideas into games and maps people can actually play. |
| **Mods and add-ons** | Adding new things to games people already love, like Minecraft. |
| **Tools, events, and websites** | The behind-the-scenes tech that keeps games, events, and communities running. |
